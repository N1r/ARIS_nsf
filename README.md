# ARIS audio demo

Audio examples for **ARIS: Low-Resource Glass-Box Neural Source–Filter Synthesis for Phonetic Stimulus Manipulation**.

Yiran Ding and Wenwei Xu · Leiden University Centre for Linguistics (LUCL), Leiden University.

## Demo

Visit [the audio demo](https://n1r.github.io/ARIS_nsf/).

The site includes copy synthesis, single-cue edits, vowel and formant continua, tone and intonation continua, and voice-source examples.

## Local preview

Open `index.html` directly, or run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8000/`.

## GitHub Pages

The static site is published from the root of the `main` branch. Audio and figures are included; no build dependencies are required.
